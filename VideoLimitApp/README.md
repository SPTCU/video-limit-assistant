# 刷视频限时助手（VideoLimit）

一个帮你**定期打断刷视频**的安卓应用：连续刷满设定时间，就自动退出（先按返回键，退不掉再回桌面），并强制休息一会儿。

不是"每日额度用完了才锁死"，而是**每隔一段时间就把你请出去一次**——把无意识的长刷切成有节奏的小段。

- 包名：`com.videolimit.app`
- 版本：1.4（versionCode 5）
- 最低支持：Android 7.0（API 24）～ Android 14
- **无任何第三方依赖、不联网、无广告、无账号**，所有数据只存在本机

## 功能

| 功能 | 说明 |
| --- | --- |
| 间隔自动退出 | 连续刷满 N 分钟（默认 10 分钟，1～120 可调），自动退出应用（返回键优先 / 直接回桌面，可切换） |
| 导航方式适配 | 自动识别当前是三键导航还是全面屏手势，也可手动指定；两种导航下都能退出，切换只影响判定时序 |
| 强制休息 | 退出后进入 M 分钟冷却（默认 2 分钟，1～30 可调），期间再打开会立刻又被退出 |
| 连续计时 | 只看"连续使用"，短暂切出去回消息（≤20 秒）不重置计时；真正离开才算断开 |
| 前台监督 | 后台服务每秒检查前台应用，系统杀进程后自动恢复，支持开机自启 |
| 轻提示 | 有悬浮窗权限时，退出瞬间在屏幕顶部显示一次提醒卡片（2.5 秒，不拦截操作） |
| 7 天趋势 | 首页展示最近 7 天刷视频总时长，仍在统计但不再用于锁定 |
| 可选应用 | 抖音、快手、B 站、小红书、微博、腾讯/爱奇艺/优酷、西瓜、好看、快手极速版等，任意勾选 |

## 使用步骤

1. 安装 APK（首次安装需允许「安装未知应用」）。
2. 打开 App，授予 **3 个权限**：
   - **无障碍（必需）**：这是"自动退出"的核心能力：到点时按返回键退出页面，退不掉则按 Home 键回桌面；
     设置 → 无障碍 → 已下载的应用 → 刷视频限时助手 → 开启。**不读取屏幕内容**。
   - **使用情况访问（必需）**：判断你在刷哪个应用、已经连续刷了多久。
   - **悬浮窗（可选）**：只在退出瞬间显示一次提醒卡片，不给也能正常退出。
   - 通知权限（Android 13+ 会弹窗，建议允许，状态栏会显示倒计时）。
3. 点「管理」，勾选要打断的 App。
4. 回到首页，打开「监督服务」开关；顺手设好「每刷几分钟退出」「休息几分钟」。「手机导航方式」默认自动识别，一般不用动。

之后：打开抖音 → 首页/通知栏出现倒计时 → 满 10 分钟自动回桌面，并提示休息 → 这 2 分钟里再点开抖音，会立刻又被送出来 → 2 分钟后重新计时。

> 想快速验证效果：把间隔调到 1 分钟、休息调到 1 分钟，试两次再调回正常值。

## 工作原理（简）

```
每秒轮询前台应用（UsageStatsManager）
   └─ 受管应用在前台 → 维持连续会话计时
        ├─ 未到点 → 更新倒计时（通知栏 + 首页）
        └─ 已到点 → ① 无障碍 performGlobalAction(GLOBAL_ACTION_HOME) 回桌面
                    ② 记录冷却截止时间
                    ③ 冷却期内再次进入 → 立即再回桌面
```

关键取舍：

- **为什么必须开无障碍**：Android 没有授权普通应用"杀死/关闭其他应用"的接口，`performGlobalAction(HOME)` 是唯一稳定、免 root 的"退出应用"手段。
- **为什么要冷却期**：只退出不冷却，用户会条件反射地立刻重开，等于没打断。
- **为什么容忍 20 秒切出**：避免回一条消息就把计时归零，导致限制形同虚设。

## 重新构建

### 方式一：一键脚本（本仓库已用此方式产出 APK）

```bash
cd VideoLimitApp
./build_apk.sh
```

产出：`VideoLimitApp/刷视频限时助手-v1.3.apk`（debug 密钥签名，可直接安装）。

脚本依赖：JDK 17+，以及用 sdkmanager 装好的组件：

```bash
sdkmanager "platform-tools" "platforms;android-34" "build-tools;35.0.0"
```

> 说明：`build-tools` 需 **35.0.0**（34 自带的 d8 与 JDK 21 编译产物不兼容，会崩在匿名类上）。
> 若 SDK 安装路径含中文，脚本会自动通过 `C:\AndroidSdk` 目录联接访问（原生命令行工具不吃中文路径）。

### 方式二：Android Studio

用 Android Studio 打开 `VideoLimitApp` 目录（已含 Gradle 配置，`compileSdk 34` / `minSdk 24`，零依赖）。

- 国内网络如果拉不动 Gradle 8.7，可把 `gradle/wrapper/gradle-wrapper.properties` 里的
  `distributionUrl` 换成腾讯云镜像：
  `https://mirrors.cloud.tencent.com/gradle/gradle-8.7-bin.zip`
- `local.properties` 已指向本机 SDK 路径，如 SDK 位置不同请修改。

## 防「自己卸载 / 自己关掉」的建议

应用本身不拦截卸载或关闭开关。想更狠一点：

- 部分手机（小米/华为/OPPO/vivo）支持「应用锁」，给本应用加锁；
- 把本应用图标从桌面隐藏，增加操作成本；
- 让家人设一个你不知道的锁屏密码。

## 已知限制

- 使用统计依赖系统 `UsageStatsManager`，少数定制系统需在「电量/后台」里允许本应用后台运行，否则服务可能被清理（本应用已做自动拉起）。
- 分屏/小窗同时开两个视频应用时，只按当前前台窗口计时。
- 微信内的「视频号」无法按应用限制（它在微信内部），可在微信「青少年模式」中另行设置。
- 极少数定制系统会限制无障碍服务反复触发 Home，若发现退不出去，请检查系统的「无障碍快捷方式/权限管理」设置。
